# Home Assistant App: Kit SOS

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Simple, clean tracker for emergency-kit items, quantities and expiry dates — with one alert per item before it expires, Home Assistant sensors and a one-click import from Grocy.

- Apple-style interface, light and dark mode, works on desktop and phone (through the Home Assistant app).
- Month-only expiry dates (e.g. "03/2027") supported.
- Alerts through Telegram or any Home Assistant notification action.
- No external dependencies, tiny footprint, data included in Home Assistant backups.

See the **Documentation** tab for details (Português / English).
